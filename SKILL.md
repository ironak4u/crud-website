# Bootstrap 6 Development Skill

## Documentation
- Documentation index: https://getbootstrap.com/llms.txt
- Full documentation: https://getbootstrap.com/llms-full.txt

## Instructions

1. Consult official Bootstrap documentation before writing code.
2. Use Bootstrap 6 syntax exclusively.
3. Never invent Bootstrap classes or components.
4. Prefer native Bootstrap components and utilities.
5. Verify unfamiliar classes and APIs against official documentation.
6. Keep HTML semantic and responsive.
7. Avoid unnecessary custom CSS.
8. If documentation is inaccessible, tell the user instead of guessing.

Always prioritize official documentation over model knowledge.
